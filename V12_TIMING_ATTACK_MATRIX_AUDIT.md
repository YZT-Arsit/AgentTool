# V12 timing attack matrix audit

The historical 16-row Walsh-Hadamard matrix derives ten labels from four independent row bits. Pairwise balance does not prevent nonlinear cross-label inference, so it is retained only as auxiliary factorial development evidence and is invalid for the primary decisive ML attack.

The repaired primary design uses task-isolated binary pairs: each randomized block contains one class-0 and one class-1 session, with only the declared target dimension changed. Classification was fixed before new timing sessions.
