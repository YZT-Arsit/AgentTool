# V6 privacy/performance profiles

## STRICT

Unified encrypted descriptor registry, resident trusted capability map, opaque
cloud client, one Gateway destination, and fixed transcript. Selected Agent,
internal/external descriptor class, and external destination are intended
private from their respective observers. Fine timing, resource privacy, and the
live long-horizon result remain open.

## CONFIDENTIAL_ENTERPRISE

Trusted selection and protected action cells remain, but internal/external
route class may be public. A cloud-local distinct Tool is private only if placed
inside confidential execution or behind an equivalent common broker.

## ENTERPRISE_EFFICIENT

Hierarchical internal-first resolution and declared cloud-local Tool category
leakage reduce work. `RESOLUTION_PARETO_V6.csv` uses actual measured 10K/100K
PIR components. `DESCRIPTOR_CACHE_RESULTS_V6.csv` shows the strict cache still
issues a dummy-row scheduled PIR query, while the efficient cache may skip it
and explicitly leak hits.

SHORT/STANDARD/LONG V6 live profile measurements are
`NOT_COMPLETED_ENVIRONMENT_WINERROR_4551`. The earlier V5 horizon data remain
development history and are not silently relabeled V6 evidence. No claim spans
profiles; profile choice must be public and secret-independent.
