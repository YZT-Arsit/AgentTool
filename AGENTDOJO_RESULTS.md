# AgentDojo results

Twenty public AgentDojo workspace/Slack user tasks supplied semantic prompts and reference actions. Baseline and M3 deterministic reference-action replays both preserved 100% benign task success and the same authorization/effect decisions.

This is not a live LLM prompt-injection evaluation. Attack success rate is recorded as `NOT_MEASURED_NO_MODEL`; consequently the result is only authorization/effect non-regression at the mechanism boundary. It does not show that M3 is a prompt-injection defense, and the full AgentDojo security non-regression gate remains not run.
