# Local V7-OHTTP Baseline Matrix

The pre-OHTTP `BASELINE_MATRIX_V7.md` remains hash-frozen. This additive matrix
defines the requested local standards-era names without rewriting that evidence.

| ID | Local path | Status | Objective exposure |
|---|---|---|---|
| B0_DIRECT_LOCAL_PROTECTED | direct local Agent action to local provider | specified | destination and natural metadata public |
| B1_PIR_PLUS_DIRECT_LOCAL | official SimplePIR then direct local provider | component evidence | lookup index protected; destination public |
| B2_OHTTP_LOCAL | OHTTP client, local Relay, local Gateway, local provider | unavailable offline | natural OHTTP size/count/timing |
| B3_OHTTP_FIXED_SIZE_LOCAL | B2 with configured fixed bodies | unavailable offline | fixed final body lengths intended |
| B4_OHTTP_FIXED_PROFILE_LOCAL | B3 plus frozen round count/lifetime | unavailable offline | fixed nominal profile intended |
| B5_STRICT_RESEARCH_PROFILE | unified SimplePIR, trusted module, OHTTP, fixed profile | unavailable offline | strict local profile target |
| B6_ENTERPRISE_EFFICIENT_RESEARCH_PROFILE | hierarchical selection and declared route-class exposure | specified, not run | internal/external route class public |
| LEGACY_DEV_TRANSPORT | custom AES-GCM local Gateway | regression evidence only | not RFC 9458 |

All endpoints in executable tests are loopback services.
